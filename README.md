# hse_qa_project_bot

Проект представляет собой телеграм бот для автоматизированного ответа на вопросы с использованием различных подходов к извлечению и генерации ответов. В проекте сравниваются четыре подхода, каждый из которых оценивается по метрикам ROUGE.

## Выбор моделей

Ввиду ограничений по GPU в 8 Гб (NVIDIA GeForce RTX 2060) и 32 Гб RAM. Было принято решение применить SLM `google/gemma-3-1b-it`, которая при своих скромных размерах имеет котекст 32k.

Для генерации эмбеддингов принята ТОП-3 модель с [ruMTEB](https://habr.com/ru/companies/X5Tech/articles/845398/) `deepvk/USER-bge-m3`, которая при своих небольши размерах имеет относительно большое контекстное окно и длину эмбеддинга. 

В связи с имеющимися ресурсными ограничениями векторное хранилище на базе [FAISS](https://pypi.org/project/faiss-cpu/) и модель для эмбеддингов разворачивается с применением RAM и CPU.

В качестве фреймворка для RAG (Retrieval Augmented Generation) применяется [langchain](https://www.langchain.com/).

## Benchmark

Бенчмарк сгенерирован по Уголовному кодексу Российской Федерации с применением [RAGAS](https://www.ragas.io/) и адаптированной на русский язык модели `IlyaGusev/saiga_nemo_12b`.

## Запуск проекта

В папке tg_bot создать файл `.env` и внести в него ключ от телеграм бота, как показано в примере `.env.example`


Чтобы запустить проект, требуется выполнить следующую команду:

```bash
docker compose up
```
